نسخه 24/7 نوبیتکس هانتر + تلگرام

هدف: صفحه HTML لازم نیست باز باشد. سرور هر 5 دقیقه بازار را بررسی می‌کند و سیگنال‌های عبورکننده از حد امتیاز را به تلگرام می‌فرستد.

راه‌اندازی:
1) این پوشه را روی یک سرویس Node.js مثل Render/Railway یا VPS قرار دهید.
2) دستور npm install و سپس npm start را اجرا کنید.
3) متغیرهای محیطی زیر را تنظیم کنید:
   TELEGRAM_BOT_TOKEN = توکن BotFather
   TELEGRAM_CHAT_ID = شناسه چت شما
   SCAN_INTERVAL_MS = 300000
   MIN_SCORE = 78
   MAX_SIGNALS = 5

امنیت: توکن تلگرام را داخل HTML یا GitHub عمومی قرار ندهید.

فایل HTML اصلی برای استفاده دستی هم داخل بسته قرار داده شده است.
